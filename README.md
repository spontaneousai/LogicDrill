测评训练
一个专为求职测评备考设计的 Claude Skill，通过自适应出题、推理式错因分析、能力画像可视化的闭环，帮助用户在北森等企业测评中提升逻辑题得分。

功能概览
自适应出题 根据你的实时作答表现动态调整题目难度和题型权重——正确率低的题型会更频繁出现，连续答对会自动升难度，连续答错则降难度建立信心。

推理式错因分析 每道错题都附带完整的推理链拆解：先还原原文逻辑，再说明正确答案为何成立，最后指出你选的那个选项具体错在哪一步（是推断过度、概念混淆、还是主旨停留表层）。不只给结论，给过程。

能力画像 每完成 10 题自动生成可视化报告，包含各题型正确率雷达图、错因分布柱状图、答题趋势曲线，以及白话版的错因说明和下阶段训练建议。

每题 90 秒计时器 模拟真实测评的时间压力，进度条在剩余 20 秒时变红闪烁提醒。

里程碑休息卡 每完成 10 题出现一次进度卡，显示当前正确率和鼓励文案，点击即可继续。

每日错题本 说"收工"或"总结今天"触发，按题型分组显示本次错因，每种错因附上通俗易懂的白话解释。

安装方法
下载 测评训练.skill 文件
打开 claude.ai → 设置 → Skills → 安装
在对话中说"开始练逻辑题"即可触发
使用方式
说这个	会发生什么
开始练逻辑题 / 出题考我	加载题库，出第一题
A / B / C / D	提交答案，查看解析
下一题	出下一道题并启动计时器
不会 / 跳过 / 看答案	直接看解析
能力画像 / 看我的数据	生成可视化能力报告
收工 / 错题本 / 总结今天	生成今日错题本
休息一下 / 我累了	立即触发里程碑休息卡
专项练习 [题型]	只出该题型题目
从头开始	重置本次会话数据
关于题库
当前内置题库
resources/北森逻辑测评题库.tsv 是作者自行整理的北森言语推理题库，共 314 道题，涵盖阅读理解、逻辑推断、细节提取、词语填空、标题选择等题型。

题库为 TSV 格式，列结构如下：

id  orig_id  ans  stem  A  B  C  D
使用自己的题库
如果你想替换或扩充题库，可以按以下步骤操作：

把你自己的题目内容（截图、文字、PDF 均可）发给 ChatGPT 或 Claude，附上以下提示词：

请将以下题目整理成 TSV 格式，列顺序为：id、orig_id、ans、stem、A、B、C、D。其中 id 从 1 开始递增，orig_id 与 id 相同，ans 为正确答案字母，stem 为题目正文，A/B/C/D 为四个选项内容。只输出数据，第一行为表头。

将生成的 TSV 文件命名后放入 skill 的 resources/ 目录，替换原有文件

重新打包 skill（如果你在本地修改）或直接在对话中上传新文件并告诉 Claude 使用它

关于疗愈模块
每完成 10 题，skill 会自动显示一张里程碑进度卡，展示正确率并提示你休息一下，然后点击继续做题。

这个功能会消耗少量额外的 token（用于渲染 widget）。如果你觉得没必要或想节省 token，可以关闭它：

解压 .skill 文件（本质是 zip）
打开 SKILL.md
找到 ## 九、疗愈小憩（Healing Break） 这一节
删除整节内容，同时在 ## 十、特殊指令响应 表格中删除"休息一下"那一行
重新打包为 .skill 文件后安装

本项目基于 Claude Skills 框架构建。SKILL.md 是 Claude 在触发 skill 时读取的指令文件，包含题库加载逻辑、自适应算法、交互流程、错因体系、可视化模板等全部行为规范。
